The Lock and Key Question

In Chapter 12 you discovered where your open chromatin regions are and which biological processes are enriched near them. But here is a deeper question that Chapter 12 cannot answer: these regions did not simply open up by themselves. Chromatin accessibility is an active biological process. Specific proteins called transcription factors bind to specific short DNA sequences called motifs, and through a cascade of molecular events, they recruit chromatin remodeling complexes that push nucleosomes aside and create the open regions your Tn5 enzyme tagged.

In a wet lab analogy, a transcription factor is like a specific restriction enzyme. Just as HindIII only cuts at the sequence AAGCTT and nowhere else, a transcription factor like PU.1 only binds efficiently at its specific 8 to 10 base pair recognition sequence. If you find that sequence systematically present inside your open chromatin regions but absent from random genomic regions, it is strong evidence that PU.1 is actively binding there and is likely responsible for maintaining the accessible chromatin state you observed.

This analysis is called motif enrichment, and it is arguably the most biologically exciting output of the entire ATAC-seq pipeline. It transforms a list of genomic coordinates into a hypothesis about which transcription factors are active in your cell type — the kind of mechanistic insight that drives experimental follow-up.

The Two-Step Strategy

Unlike Chapter 12 where we could submit the narrowPeak coordinate file directly, motif analysis requires something different. A motif enrichment tool does not work with genomic coordinates — it works with actual DNA letter sequences. It needs to look at the A, C, G, T content inside your peaks and search for patterns.

This means we have to do one preparatory step in the terminal: extract the DNA sequences from inside our peaks and save them in a format called FASTA. Think of the narrowPeak file as a list of addresses, and the reference genome as the city map. We need to physically go to each address on the map and copy down what the building looks like. The tool that does this is bedtools getfasta, which is already installed in your environment from Chapter 9.

Once we have the FASTA file, we upload it to the MEME Suite web server at meme-suite.org. MEME Suite runs the entire motif analysis on their servers — their computers do the heavy computational work and return the results to your browser. No installation, no disk space consumption on your machine, and no compatibility issues.

Preparing the Input — Extracting Peak Sequences

First, confirm you are in your project directory with your environment active:

cd ~/atacseq_og

conda activate bio-tools

We will use bedtools getfasta to extract the DNA sequences from within each of our peaks. This command needs two inputs: the peak coordinates file and the reference genome FASTA file. You already have both — the peak file from Chapter 8 and the chr19 reference genome downloaded in Chapter 7. 

bedtools getfasta -fi reference_data/chr19.fa -bed results/peaks/ENCFF535OGL_peaks.narrowPeak -fo results/peaks/peak_sequences.fa

Let us break this command down completely.

bedtools getfasta is the specific subcommand of bedtools that extracts sequences from a genome using a set of coordinates. Think of it as a molecular scissors that cuts out exactly the pieces of the reference genome that correspond to your peak locations.

-fi reference_data/chr19.fa specifies the Fasta Input — the reference genome sequence file. This is the file we downloaded and unzipped in Chapter 7. It contains the actual A, C, G, T sequence of every base pair in Chromosome 19.

-bed results/peaks/ENCFF535OGL_peaks.narrowPeak tells bedtools which coordinates to extract. The -bed flag specifies that the coordinate file is in BED or BED-like format. Our narrowPeak file qualifies because its first three columns are chromosome, start, and end — exactly what bedtools needs to locate each region.

-fo results/peaks/peak_sequences.fa specifies the Fasta Output file where the extracted sequences will be saved. The .fa extension indicates FASTA format, which is a standard plain text format for storing DNA sequences.

The command runs silently and returns the prompt when finished. To confirm it worked:

wc -l results/peaks/peak_sequences.fa

In FASTA format, every sequence is represented by two lines: a header line beginning with > that contains the sequence name, and a sequence line containing the actual letters. Since each of your peaks generates one sequence, the total number of lines should be approximately double your peak count. If you had 847 peaks, expect around 1694 lines.

Look at the first few entries to confirm the format looks right:

head -6 results/peaks/peak_sequences.fa

You will see output like this:

>chr19:3204500-3205200
ATCGATCGATCGATCG...
>chr19:4102300-4103100
GCTAGCTAGCTAGCTA...

Each > header line shows the chromosomal coordinates of the peak, and the line below it contains the DNA sequence extracted from that exact location in the mm10 reference genome. These are the sequences we are going to search for transcription factor motifs.

Trimming Sequences to the Peak Summit

There is one refinement worth making before submission. As discussed in Chapter 8, each peak has a summit — the single base pair with the highest read pileup, representing the most likely center of the open chromatin region. Transcription factor motifs are concentrated right at this summit. If we submit the full peak sequence, which can be 500 to 1000 base pairs long, we dilute the motif signal with flanking sequence that contains less useful information.

The standard approach in ATAC-seq motif analysis is to use a fixed window of 200 base pairs centered on the summit of each peak. To do this, we first need to create a new BED file that contains the summit-centered coordinates rather than the full peak coordinates. Recall from Chapter 11 that column 10 of the narrowPeak file contains the offset from the peak start to the summit. 

awk '{summit=$2+$10; start=summit-100; end=summit+100; if(start<0) start=0; print $1"\t"start"\t"end}' results/peaks/ENCFF535OGL_peaks.narrowPeak > results/peaks/peak_summits_200bp.bed

This is the most complex awk command in the handbook so far. Let us walk through it step by step, treating it like a protocol with multiple stages.

summit=$2+$10 calculates the absolute genomic position of the summit. Column 2 ($2) is the peak start coordinate, and column 10 ($10) is the number of base pairs from that start to the summit. Adding them gives the exact chromosomal position of the summit.

start=summit-100 and end=summit+100 define a window of 100 base pairs on each side of the summit, giving a total of 200 base pairs centered on the summit.

if(start<0) start=0 is a safety check. If a peak is very close to the beginning of the chromosome, subtracting 100 from the summit position might produce a negative number, which is not a valid genomic coordinate. This line catches that situation and sets the start to zero instead.

print $1"\t"start"\t"end prints the chromosome name, the new start, and the new end, separated by tabs (\t). The result is a clean three-column BED file.

> redirects the output to a new file called peak_summits_200bp.bed.

Now extract sequences from this summit-centered file:

bedtools getfasta -fi reference_data/chr19.fa -bed results/peaks/peak_summits_200bp.bed -fo results/peaks/peak_summit_sequences.fa

This is identical to the previous bedtools getfasta command except we are now using the summit-centered coordinates instead of the full peak coordinates. The result is a FASTA file where every sequence is exactly 200 base pairs long, centered on the open chromatin summit. This is the file we will upload to MEME Suite.

Confirm it looks right:

head -4 results/peaks/peak_summit_sequences.fa

Each sequence line should now be 200 characters long, one character per base pair.

Checking File Size Before Upload

The MEME Suite web server accepts files up to 60 megabytes. Our dataset is small, but it is good practice to check before attempting a submission. 

ls -lh results/peaks/peak_summit_sequences.fa

For 847 peaks at 200 base pairs each, the file will be well under 1 megabyte. You are comfortably within the server’s limit.

Submitting to MEME Suite — AME

Open your web browser and navigate to:

https://meme-suite.org/meme/tools/ame

We are using the AME tool specifically, which stands for Analysis of Motif Enrichment. Within the MEME Suite, AME is the tool designed for exactly our question: given a set of sequences, which known transcription factor motifs are statistically enriched? This is the most appropriate tool for ATAC-seq data where you have a defined set of peak sequences and want to match them against a database of known motifs.

The submission form has several sections. Work through them carefully.

Step 1 — Input Sequences: Click “Choose File” and navigate to results/peaks/peak_summit_sequences.fa on your computer. This is the FASTA file you just created. After selecting it, you should see the filename appear next to the button confirming it was loaded.

Step 2 — Control Sequences: Leave this set to “Shuffle input sequences.” This is important to understand. AME needs a background set of sequences to compare against, exactly the same concept as the background in GREAT. By selecting shuffle, you are telling AME to generate background sequences by randomly rearranging the letters in your actual peak sequences. This preserves the overall base composition of your sequences (their GC content) while destroying any real biological patterns — a statistically sound approach to background generation that is standard practice in the field.

Step 3 — Motif Database: Click the dropdown under “Select motif databases” and select “JASPAR Core Vertebrates (2024)” or the most recent JASPAR vertebrates option available. JASPAR is the gold standard public database of transcription factor binding motifs, curated from thousands of ChIP-seq and protein binding experiments. By selecting the vertebrates collection you ensure it includes all mouse and human transcription factor motifs relevant to our experiment.

Step 4 — Advanced Options: Leave all other settings at their defaults for now. The default statistical threshold and scoring method are appropriate for a standard ATAC-seq motif analysis.

Step 5: Click Submit. AME will queue your job and display a job ID. For a file this size the analysis typically completes within 2 to 5 minutes. The page will automatically update when your results are ready, or you can bookmark the results URL and return to it later.

Interpreting the AME Results

When the analysis finishes, AME presents its results as a ranked table of enriched motifs. Each row represents one transcription factor motif from the JASPAR database. They are ordered from most enriched to least enriched. Let us go through what each column means.

Rank — The position in the ranked list. Rank 1 is the most significantly enriched motif in your peaks.

Motif ID and Motif Alt ID — The database identifier and the common name of the transcription factor. The common name is what you would look up in a biology textbook. For example, “MA0080.5” is the database ID and “SPI1” is the common name — SPI1 is the gene name for PU.1, the master regulator of myeloid cell identity.

Consensus — A simplified version of the motif sequence showing the most common base at each position. This is a text representation of what the sequence logo shows visually.

p-value — The statistical significance of the enrichment. This is calculated by comparing how frequently the motif appears in your peak sequences versus the shuffled background sequences. A smaller p-value means the enrichment is less likely to be due to chance.

adj. p-value — The p-value adjusted for multiple testing. Since AME tests hundreds of motifs simultaneously, it corrects for the fact that some enrichments would appear significant purely by chance. This is the value you should use when deciding which results to trust.

% Sequences with Motif (in peaks) — The percentage of your peak sequences that contain at least one instance of this motif. If 65% of your peaks contain a PU.1 motif, it means PU.1 binding sites are present in nearly two thirds of your open chromatin regions — a very strong signal.

% Sequences with Motif (in background) — The same statistic for the shuffled background sequences. The contrast between this number and the previous one is where the enrichment story lives. If 65% of peaks have the motif but only 12% of background sequences do, that is a dramatic and meaningful enrichment.

The Sequence Logo

For each motif in the results table, you can click on the motif name to see its sequence logo. This is a graphical representation where each position of the motif is shown as a stack of letters. The height of the entire stack at a position indicates how important that position is for binding — tall stacks mean that base is almost always the same in real binding sites. The height of each individual letter within the stack indicates how often that specific base appears. These logos are the same images you see in published papers and in transcription factor databases like JASPAR and ENCODE.

The Biological Interpretation

Step back and consider what a meaningful result looks like for our specific dataset. We are analyzing ATAC-seq data from mouse monocytes — innate immune cells derived from the myeloid lineage. Several transcription factors are known to be master regulators of myeloid cell identity and are expected to show up near the top of any monocyte ATAC-seq motif analysis:

PU.1 (SPI1) is perhaps the single most important transcription factor for myeloid cell identity. It is a pioneer factor, meaning it has the ability to bind to compacted chromatin and initiate the opening process. Finding PU.1 motifs at the top of your enrichment list in a monocyte dataset would be strong biological validation that your experiment captured the true regulatory landscape of the cell type.

C/EBP family members (CEBPA, CEBPB, CEBPE) are co-regulators of myeloid differentiation that work closely with PU.1. Their motifs are typically enriched in monocyte and macrophage ATAC-seq data.

AP-1 family members (FOS, JUN, FOSL2) are broadly active in many cell types but particularly so in monocytes and macrophages due to their role in inflammatory signaling.

If these names appear near the top of your AME results with small adjusted p-values and high percentages of peaks containing the motif, it means your experiment successfully captured biologically meaningful open chromatin in the correct cell type. This is the computational equivalent of running a positive control that came out exactly as expected.

What if you see unexpected results? Remember that our toy dataset only covers Chromosome 19, which represents about 3% of the mouse genome. The motif enrichment results from this subset may not perfectly represent what you would find in a full genome-wide analysis. Some expected motifs might not reach statistical significance simply because the sample size is small. This is not a failure — it is a consequence of the deliberate trade-off we made in Chapter 7 to use a single chromosome to keep the analysis accessible on a laptop.

Saving Your Results

Just like with GREAT in Chapter 12, AME results are not permanently stored on the server. Save them before closing the browser.

Look for the “Download” button or link on the AME results page. This will give you a zip archive containing a plain text file called ame.tsv — a tab-separated table of all enriched motifs with their statistics — as well as the HTML report with the visual logos.

Once downloaded, move these files to your results folder:

mkdir -p results/motifs

mv ~/Downloads/ame_out.zip results/motifs/

cd results/motifs/

unzip ame_out.zip

unzip extracts the contents of a zip archive into the current folder. After running it, you will have all the AME result files organized inside results/motifs/.

You can do a quick inspection of the text results file from the terminal:

head -20 results/motifs/ame.tsv

This gives you the top enriched motifs as a plain text table that you can filter and sort using the awk and sort commands from Chapter 11 if you want to do further terminal-based exploration.

The Complete Picture

Step back for a moment and consider what you have accomplished across Chapters 11, 12, and 13. You started with a file of raw coordinates output by MACS2. In Chapter 11 you learned to interrogate those coordinates directly — counting peaks, ranking them by strength, filtering for regions of interest. In Chapter 12 you annotated them with GREAT, discovering which genomic features they overlap with and which biological pathways are enriched near them. And now in Chapter 13 you have extracted the DNA sequences from inside those peaks, submitted them to a motif analysis server, and identified which transcription factor binding sequences are statistically overrepresented — giving you a mechanistic hypothesis about who is responsible for the chromatin accessibility you observed.

This is the complete interpretive arc of an ATAC-seq experiment: from raw coordinates to molecular mechanism. In a real research project, the motif enrichment results would generate specific testable hypotheses. If PU.1 motifs are the most enriched, you might follow up with a ChIP-seq experiment to confirm that PU.1 actually occupies those sites, or a knockdown experiment to test whether removing PU.1 closes the chromatin at those regions. Every downstream experiment in the wet lab starts from a computational observation like the one you just made.
